# bambu-cost: себестоимость печати Bambu Lab A1

Один сервис: слушает принтер по LAN (MQTT), считает себестоимость, ведёт склад катушек,
отдаёт веб-интерфейс и HTTP API (для Telegram-бота). Интернет не нужен.

## Запуск (Windows или Orange Pi, Node.js 22.13+)
    npm install
    cp config.example.json config.json    # token, порт, данные принтера
    npm start                              # интерфейс: http://<адрес>:8080

В config.json остаётся только запуск (token, port, dbPath, slicedFilesDir). Принтер при первом
запуске подхватывается из него, всё остальное (тариф, мощность, амортизация, наценка, порог остатка)
правится на вкладке «Настройки». Токен интерфейс спросит один раз.

Автозапуск на Pi (systemd): ExecStart=/usr/bin/npm start, WorkingDirectory=путь к проекту, Restart=always.
База: встроенный SQLite из Node (`node:sqlite`), компилировать ничего не нужно. При старте Node напишет
ExperimentalWarning про SQLite: это нормально.

## Как пользоваться (без AMS)
1. Нарезали → «Проверка перед печатью» → загрузили .gcode.3mf (файл сохранится на сервере).
2. Выбрали катушки по слотам, увидели «хватает / впритык / не хватает», нажали «Запомнить выбор».
3. Печатаете, меняете катушки на паузе. Пауза считается отдельно (мощность «на паузе»).
4. По окончании остаток катушек списывается автоматически. Взвешивание → «Взвесить» корректирует остаток.
Задание без выбранной катушки берёт ближайшую по типу и цвету; поправить можно в «Истории».

## Вкладка «Заказы» (из Telegram-бота)
Показывает заказы бота, их статус и себестоимость (по привязанным печатям). Смена статуса работает как кнопки админа
в боте: клиент получает уведомление, очередь в канале обновляется. Для этого у бота должен быть calc.py версии
с `start_api`, а в .env бота CALC_TOKEN. Бот слушает локально 127.0.0.1:8081 (BOT_API_PORT), калькулятор ходит
к нему сам; другой адрес можно задать в config.json: "botUrl". Версия берётся из package.json (поле version).

## API для бота (заголовок Authorization: Bearer <token>)
    GET  /api/jobs, /api/jobs/{id}      себестоимость (total_cost) и цена клиенту (price)
    PUT  /api/jobs/{id}                 {"order_id": "123"}  - привязать заказ
    GET  /api/spools                    остатки и статусы (ok / low / empty)
    GET  /api/settings, PUT /api/settings

    import requests
    H = {"Authorization": "Bearer <token>"}
    requests.put("http://pi:8080/api/jobs/5", json={"order_id": "A-17"}, headers=H).json()["price"]
